# Dataset license matrix

| Dataset | Classification | Commercial build action | Required attribution/notes |
|---|---|---|---|
| FoodOn | commercially usable with attribution | may ship ontology-derived IDs/terms | CC BY 4.0 |
| USDA FDC | commercially usable subject to source terms | use downloaded release with notice | cite USDA; verify individual records |
| FooDB | non-commercial/restricted for commercial redistribution | quarantine or obtain permission | cite FooDB and underlying sources |
| FlavorDB2 | non-commercial/share-alike | research branch only unless licensed | CC BY-NC-SA 3.0 |
| Pyrfume | non-commercial/source-dependent | inspect each archive before use | FAIR/non-commercial default |
| Open Food Facts | share-alike database | separate ODbL database and comply with share-alike | attribution; images separate |
| Phenol-Explorer | unclear/restricted for commercial bulk use | permission required | cite database and papers |
| FEMA | unclear for bulk extraction | use as linked reference; no blanket safety claims | conditions of intended use matter |
| RecipeDB | non-commercial/share-alike | research benchmark only | CC BY-NC-SA 3.0 |
| Recipe1M+ | research-only/non-commercial | do not commercialize corpus/model trained on it without permission | gated terms |
| Indian 6000+ | candidate CC BY 4.0, provenance needs verification | retain source/license manifests | source website rights may differ |
| Kaggle derivatives | unclear | reject until explicit license | downloadability is not permission |

This matrix is a research engineering classification and not legal advice. Any commercial release needs counsel review, especially where database rights, source-site terms, or share-alike obligations interact.
