# Acquisition blocker

The public links expose downloadable files, but acquisition is not the same as permission. The two corpus candidates closest to the target—Mendeley 6000+ and INDoRI—both document web-crawled source material and lack confirmed underlying-content rights in the reviewed primary materials. Mendeley download attempts in this environment returned HTTP 403, while the INDoRI public Figshare access was inconsistent/private. No raw snapshot was written.

This is a deliberate stop condition. Do not bypass access controls, scrape the source site, or infer permission from a mirror's CC label.
