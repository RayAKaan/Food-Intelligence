# Corpus-relative novelty baseline

Novelty is computed only relative to an explicitly indexed corpus. Pair labels are `COMMON`, `UNDERREPRESENTED`, `RARE_IN_INDEXED_CORPUS`, or `UNKNOWN` when no corpus is available. A rare pair is not unprecedented, novel in the world, safe, pleasant, or experimentally validated.

Current result: `UNKNOWN` for research because no recipe index is admitted. The commercial supplement is too small for a useful novelty model.
