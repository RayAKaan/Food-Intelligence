# Indian recipe license audit

## Mendeley 6000+ corpus

The primary Mendeley page identifies version 1, DOI `10.17632/xsphgmmh7b.1`, CSV/XLS files, and displays CC BY 4.0. Its description also states that the dataset was created from Archana's Kitchen and that a crawler/cleaning pipeline exists on GitHub. The GitHub README confirms the data was created by crawling/scraping Archana's Kitchen. No permission grant from Archana's Kitchen, source-site terms allowing redistribution, or chain-of-title record was found in the reviewed primary materials. Result: **LICENSE_NOT_CONFIRMED for the underlying content**.

## INDoRI

The paper reports 5,187 recipes collected from seven online platforms and 18 cuisines/regions. The public Figshare item displays CC BY 4.0, but the item access is inconsistent/private in the reviewed page, and the paper explicitly describes crawling websites. The dataset-level label therefore does not by itself prove rights to the underlying recipe text. Result: **LICENSE_NOT_CONFIRMED for commercial use or redistribution**.

## INDB

The repository documents 1,014 recipes from two named cookbooks plus 148 website recipes and links to source files. It is an important structured quantity/nutrition resource, but no clear dataset-wide license was located, and the cookbook/web components have distinct rights. Result: **LEGAL_REVIEW_REQUIRED**.

## Other mirrors

Kaggle/GitHub mirrors report CC0/CC BY claims for Archana-derived files, but the mirror metadata cannot cure missing rights from the originating publisher. The cleaned Kaggle derivative explicitly reports an unknown license in its metadata. These are not accepted as clean-room sources.

## Decision

No raw recipe corpus is acquired. No scraper is added. The correct next action is rights confirmation or a licensed data agreement, not technical workarounds.
