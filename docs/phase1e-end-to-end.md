# Phase 1E — End-to-End Intelligence Substrate

The deterministic substrate now composes query planning, graph retrieval, multi-view retrieval, hard constraints, compatibility v2, novelty, evidence metadata, ranking, and compatibility/novelty Pareto selection in one executable pipeline.

## Scientific boundary

Bundled benchmark data remain synthetic. No synthetic result is a scientific claim. Real recipe benchmarks require an authorized, versioned corpus and leakage-safe splits.

## Reproducibility

A pipeline result records the query, plan, scoring configuration, evidence metadata, and algorithm version. Missing novelty or compatibility evidence is preserved rather than fabricated.
