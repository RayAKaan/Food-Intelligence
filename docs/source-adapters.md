# Source adapters

`SourceAdapter` defines `discover`, `validate`, `retrieve`, `parse`, `normalize`, `map`, and `emit`. Current metadata-only adapters are registered for FoodOn, USDA FDC, FooDB, FlavorDB2, Pyrfume, Phenol-Explorer, and FEMA. They do not download data. Each source has an explicit research/commercial status and can be replaced without changing the representation layer.
